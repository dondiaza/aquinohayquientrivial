# Ecosistema de modos de juego ANHQV

Total: **48 modos de juego**.

Estos modos combinan el banco maestro de preguntas, tarjetas, retos, filtros de spoiler, rankings, rachas y coleccionables.

# Eventos recurrentes sugeridos

**Diario:** Desengaño Daily (7 preguntas), carta de personaje y racha.
**Semanal:** Junta semanal (25 preguntas), clasificación y una categoría rotatoria.
**Mensual:** Vecino del mes, colección temática y reto experto.
**Nochevieja:** Campanadas, contenido dedicado a 2004-2006.
**Aniversario de estreno:** Noche de estreno, temporada 1 y mapa original.
**Final de temporada:** Última junta, activable solo si el usuario permite spoilers major.
